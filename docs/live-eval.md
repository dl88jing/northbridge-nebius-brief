## How to read this

- Costs are the API-reported token counts times Token Factory list prices in `lib/pricing.ts` (read 2026-10-25), not an invoice.
- Tavily results are cached per server instance for 6 hours, so later runs on a warm instance may reuse sources and spend fewer credits. In this sample every run reused cached Tavily sources (0 credits), so the server times above exclude fresh web research; a cold run with fresh web research takes longer and spends Tavily credits.
- The citation checks are mechanical: every `[n]` must point at a source in the brief, and sources must be real URLs. They do not prove a source is the best one or that the model read it correctly; a human still reviews each brief, which is the point of the product.
- Small sample (5 runs, one household). It shows stability and cost on the deployed app, not general accuracy.
